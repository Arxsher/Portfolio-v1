AegiLabs

AI agents for workflow automation

Live site(opens in a new tab)GitHub(opens in a new tab)

AegiLabs is a full product site and app for an AI-agent automation platform: agents that are designed, deployed, and monitored for support, sales, reporting, and internal ops.

Visitors land on an animated marketing page with a custom ASCII 3D renderer written from scratch on a canvas. Signed-up users configure their own agent through an onboarding flow, then manage and chat with it from a dashboard.

The agent sandbox streams responses from Llama 3.3 70B on Groq, with a system prompt built dynamically from each user's saved agent config: role, connected tools, and autonomy level.

Key features

  • Marketing Site: 15 isolated landing sections, including a hand-written ASCII 3D canvas renderer.
  • Authentication: Clerk SSO with protected routes, degrading gracefully when keys are absent.
  • Onboarding: Agent name, use case, tools, model preference, and autonomy level, saved via server actions.
  • Chat Sandbox: Streaming agent chat on Groq through the Vercel AI SDK.
  • Database: Supabase Postgres with row-level security.
